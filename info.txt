RAG Pipeline — HuggingFace + Chroma + LangChain
===============================================

QUICK START
-----------
1.  pip install -r requirements.txt
2.  Copy your PDF files into  data/raw/
3.  python app.py --ingest          ← builds the vector store (run once)
4.  python app.py --query "..."     ← single question
    python app.py                   ← interactive Q&A loop

FOLDER STRUCTURE
----------------
app.py                      Main entry point
requirements.txt
data/
  raw/                      Drop your PDFs here
src/
  config.py                 All settings (LLM, chunking, paths, …)
  utils/
    logger.py               Centralised logging setup
  data_ingestion/
    load_documents.py       Loads PDFs → LangChain Documents
  preprocessing/
    text_splitter.py        Splits documents into chunks
  embeddings/
    vectore_store.py        Chroma DB — build & load
  retrieval/
    retrival.py             Similarity retriever
  llm/
    llm_model.py            HuggingFace LLM (ChatHuggingFace)
  pipeline/
    rag_pipeline.py         Wires every module end-to-end
  tests/
    test_pipeline.py        Unit tests

RUNNING TESTS
-------------
  python -m pytest src/tests/ -v
